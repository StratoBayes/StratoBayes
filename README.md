# StratoBayes

StratoBayes is software for automated stratigraphic correlation and age modelling from StratoBayes Limited, a Durham University spin-out. Please use the issues in this repository to report bugs and request features, or email [support@stratobayes.com](mailto:support@stratobayes.com) for anything you prefer not to post publicly.

- Website and sign-up: [www.stratobayes.com](https://www.stratobayes.com)
- Installation and documentation: [stratobayes.github.io](https://stratobayes.github.io/software.html)
- Method: Eichenseer, K., Sinnesael, M., Smith, M. R. and Millard, A. R. (2025). StratoBayes: a Bayesian method for automated stratigraphic correlation and age modelling. *Geochronology* 7(4), 545–570. [doi:10.5194/gchron-7-545-2025](https://doi.org/10.5194/gchron-7-545-2025)
